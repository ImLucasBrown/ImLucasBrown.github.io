NXT — Node Execution Tree

Role: Co-author & Developer
Language: Python · Qt GUI
NXT layers and composites Python nodes like Photoshop layers, visualizing attribute inheritance and execution flow. The artist friendly UX bridges the gap between one-off scripting and general purpose tools.
NXT currently powers multiple production workflows, including rig builds for several major studios.
